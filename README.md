## Installation

```bash
git clone https://github.com/<user>/opc-n3-summary.git
cd opc-n3-summary
python -m venv .venv
source .venv/bin/activate         # Windows: .venv\Scripts\activate
pip install -r requirements.txt   # or: pip install .
```

## Run

```bash
python opc_n3_summary.py <log.csv>
```
